# MontaGest Legal

Site público mínimo para hospedar a Política de Privacidade e as instruções de exclusão de dados do MontaGest via GitHub Pages.

## Arquivos públicos

- `privacy-policy.html` — Política de Privacidade
- `data-deletion.html` — instruções de exclusão de dados
- `index.html` — página inicial legal
- `legal.css` — estilos

## Publicação no GitHub Pages

1. Crie um repositório público chamado `montagest-legal` na conta `Dupand`.
2. Envie **o conteúdo desta pasta para a raiz do repositório**.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

URLs esperadas:

- `https://dupand.github.io/montagest-legal/`
- `https://dupand.github.io/montagest-legal/privacy-policy.html`
- `https://dupand.github.io/montagest-legal/data-deletion.html`

Use a URL da Política de Privacidade no painel da Meta somente depois de confirmar que abre publicamente em uma janela anônima.

## Segurança

Este pacote não contém código do MontaGest, banco de dados, `.env`, tokens ou credenciais.
